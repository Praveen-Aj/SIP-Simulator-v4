# 📦 SIP Simulator - Installation Guide

## 🎯 **For End Users (Your Teammates)**

---

## 📋 **System Requirements**

- **Operating System:** Windows 7, 8, 10, or 11 (64-bit)
- **Disk Space:** 100 MB free space
- **RAM:** 512 MB minimum (1 GB recommended)
- **Java:** NOT required (bundled in installer)
- **Admin Rights:** NOT required

---

## 🚀 **Installation Steps**

### **Step 1: Get the Installer**

You will receive a file named:
```
SIP_Simulator_Setup_v1.0.exe
```

**File Size:** ~31 MB

---

### **Step 2: Run the Installer**

1. **Locate the file** on your computer (usually in Downloads folder)

2. **Double-click** `SIP_Simulator_Setup_v1.0.exe`

3. **Windows SmartScreen** may appear:
   - Click **"More info"**
   - Click **"Run anyway"**
   - This is normal for new software

---

### **Step 3: Follow Installation Wizard**

#### **Welcome Screen:**
- Click **"Next"**

#### **Select Destination Location:**
- Default: `C:\Program Files\SIP Simulator\`
- You can change this if needed
- Click **"Next"**

#### **Select Additional Tasks:**
- ✅ **"Create a desktop icon"** - Keep this checked!
- Click **"Next"**

#### **Ready to Install:**
- Review your choices
- Click **"Install"**

#### **Installing:**
- Wait 1-2 minutes while files are copied
- Progress bar will show installation status

#### **Completing Setup:**
- ✅ Check **"Launch SIP Simulator"** to start immediately
- Click **"Finish"**

---

## ✅ **Installation Complete!**

### **What You'll See:**

1. **Desktop Icon:**
   - Look for "SIP Simulator" icon on your desktop
   - This is your main way to launch the app

2. **Start Menu Entry:**
   - Press Windows key
   - Type "SIP Simulator"
   - You'll see the app in search results

## 🔧 **Troubleshooting**

### **Problem: Installer won't run**

**Solution:**
- Right-click the installer
- Select "Run as administrator"
- Follow the wizard

---

### **Problem: Windows SmartScreen blocks it**

**Solution:**
- Click "More info"
- Click "Run anyway"
- This is safe - it's just a new application

---

### **Problem: Desktop icon not created**

**Solution:**
- Go to: `C:\Program Files\SIP Simulator\`
- Right-click `SIP_Simulator.exe`
- Select "Send to" → "Desktop (create shortcut)"

---

### **Problem: Application won't start**

**Solution 1: Check installation**
- Verify installation completed successfully
- Reinstall if needed

**Solution 2: Check antivirus**
- Some antivirus may block new applications
- Add SIP Simulator to whitelist

**Solution 3: Check Windows version**
- Requires Windows 7 or later
- Update Windows if needed

---

### **Problem: Fonts look strange**

**Solution:**
- This is rare, but if fonts look odd:
- Go to Options → Themes
- Try different themes (Light/Dark)
- Restart the application

## 🗑️ **Uninstallation**

If you need to remove SIP Simulator:

### **Method 1: Start Menu**
```
1. Press Windows key
2. Type "SIP Simulator"
3. Right-click the app
4. Select "Uninstall"
5. Follow the wizard
```

### **Method 2: Control Panel**
```
1. Open Control Panel
2. Go to "Programs and Features"
3. Find "SIP Simulator"
4. Click "Uninstall"
5. Follow the wizard
```

### **Method 3: From Start Menu Folder**
```
1. Press Windows key
2. Find "SIP Simulator" folder
3. Click "Uninstall SIP Simulator"
4. Follow the wizard
```

**What Gets Removed:**
- ✅ Application files
- ✅ Desktop shortcut
- ✅ Start Menu entries
- ✅ Bundled Java runtime

**What Stays:**
- Your saved scenarios (if any)
- Your settings (if any)
- Log files (if any)
