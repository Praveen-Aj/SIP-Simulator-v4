================================================================================
QUICK ANSWERS TO COMMON QUESTIONS
================================================================================

Q: Can we use GPL v3 code in a commercial product?
A: YES, but you must provide source code and use GPL v3 license

Q: Can we keep our modifications proprietary?
A: NO, GPL v3 requires all modifications to be open-source too

Q: Do we need to pay royalties?
A: NO, GPL v3 is free (but requires compliance)

Q: Can we sell GPL v3 software?
A: YES, but you must still provide source code at same/lower cost

Q: What if we just keep it internal?
A: SAFE, internal use has no obligations under GPL v3

Q: Can we use it in a proprietary product?
A: ONLY if you open-source your modifications or get alternative license

Q: Is GPL v3 really enforceable?
A: YES, multiple lawsuits have been won on GPL violations

Q: Do we need customer permission to use GPL v3?
A: You need to DISCLOSE the GPL v3 license in contracts
