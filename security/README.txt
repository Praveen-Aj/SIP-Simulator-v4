SIP Inspector Security Directory
==================================

This directory stores TLS/SSL certificates and keys:

Files:
------
- private.pem           : Private key (generated by Tools/Security Keys)
- public.pem            : Public key (generated by Tools/Security Keys)
- certificate.crt       : Self-signed certificate (generated by Tools/Security Certificate)
- SIPInspKeystore.jks   : Java keystore (contains private key + certificate)
- SIPInspTruststore.jks : Java truststore (contains trusted server certificates)

Usage:
------
1. Generate keys: Tools -> Security Keys
2. Generate certificate: Tools -> Security Certificate
3. For client mode: Trusts all self-signed certificates by default
4. For server mode: Add your certificate to keystore

Note: Keystore password is "changeit" by default
